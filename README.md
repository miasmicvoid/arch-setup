As such, this repo is necessary to be kept even after installation. It will eventually also include some customizations on my arch system I can't care to remember repeating until an issue comes up, so might as well save them here. 
Also includes a package list, and might other things down the line.

Heavily inspired by diinkis retrodark theme, though some/a lot of it has been somewhat rewritten and customized.
